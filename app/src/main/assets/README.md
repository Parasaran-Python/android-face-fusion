# Assets

Models auto-download from HuggingFace on first launch. For manual setup, place these files here:

```
assets/
├── det_10g.onnx       (~16 MB)  Face detection
├── w600k_r50.onnx     (~166 MB) Face embedding
├── inswapper_128.onnx (~553 MB) Face swapping
└── emap.bin           (~1 MB)   Embedding transform matrix (pre-extracted)
```

Download: https://huggingface.co/leonelhs/insightface
